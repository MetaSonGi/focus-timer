뽀모도로 테크닉 기반 집중 타이머 + 세션 기록 웹앱.


## 기능

- ⏱ 집중 25분 / 휴식 5분 / 휴식 15분 + 직접 설정
- ⭕ SVG 링 타이머 + 브라우저 탭 제목에 남은 시간 표시
- 🔔 세션 완료 시 알림음 (Web Audio)
- 📊 오늘 집중 시간·세션 수·연속 일수
- 📈 최근 7일 막대 차트
- 🕘 세션 로그 (할 일 메모 포함)
- 💾 모든 기록은 브라우저 localStorage에 저장 (서버 없음)

## 기술

- Vanilla JS + SVG + Web Audio API
- 완전 클라이언트 사이드
